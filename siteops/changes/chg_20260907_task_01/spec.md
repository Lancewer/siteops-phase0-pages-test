# Spec — chg_20260907_task_01（极简计算器页面）

## 1. 概述
在 `public/index.html` 交付一个单文件、零依赖的极简网页计算器，支持四则运算。

## 2. 功能规格
- 显示区：展示当前输入/结果；初始为 `0`。
- 数字键：`0`–`9`、小数点 `.`。
- 运算符键：`+` `−` `×` `÷`（UI 可用符号，内部映射 `+ - * /`）。
- 控制键：`C`（清空，回到初始状态）、`=`（计算并展示结果）。
- 运算语义：
  - 支持连续运算：`1 + 2 + 3 =` → `6`（每次按运算符即结算上一步）。
  - 除零：显示 `Error`，按 `C` 或任意数字键可复位。
  - 结果保留合理精度（最多 10 位有效小数，去除多余尾随 0），如 `10 ÷ 4 = 2.5`。
  - 重复小数点在同一段输入中只允许一次。
- 可选（nice-to-have）：键盘输入支持（数字、运算符、Enter 为 `=`、Escape 为 `C`）。

## 3. UI 规格
- 极简风格：居中卡片布局，网格按钮（4 列），等号键可占常规格位即可（不要求跨列）。
- 基础可用性：按钮可点击、显示区只读、移动端 viewport meta 存在。
- 全部 CSS/JS 内联于该文件，无外部资源引用。

## 4. 技术约束
- 单一交付文件：`public/index.html`。
- 无构建步骤、无第三方库/CDN/字体外链。
- HTML 需合法（`<!DOCTYPE html>`、闭合标签、viewport meta）。

## 5. 验收用例（verification 依据）
| 用例 | 操作序列 | 期望 |
|---|---|---|
| AC1 | 2 + 3 = | 显示 5 |
| AC2 | 7 − 4 = | 显示 3 |
| AC3 | 6 × 8 = | 显示 48 |
| AC4 | 9 ÷ 3 = | 显示 3 |
| AC5 | 10 ÷ 4 = | 显示 2.5 |
| AC6 | 1 + 2 + 3 = | 显示 6 |
| AC7 | 5 ÷ 0 = | 显示 Error |
| AC8 | C | 复位显示 0 |
| AC9 | 查看源码 | 无任何 http(s) 外部资源引用 |

## 6. 边界与不做项
- 不支持负数输入键、百分比、括号、退格（不阻止输入负中间结果）。
- 不做单元测试框架接入；验证用浏览器/人工抽查。
- 不改动站点任何现有文件。
